# iMac18,3 CS8409 Fedora 内蔵スピーカーパッチ 日本語補足

このリポジトリは、2017年 27インチ iMac 5K / iMac18,3 に Fedora Linux を導入した際、CS8409 / CS42L83 / TAS576 系の内蔵スピーカーを鳴らすためのパッチと検証記録を公開するものです。

メインの説明は英語版 `README.md` に記載しています。
この日本語版は、提供者が日本語話者であること、現在の到達点、未対応部分、そして検証フィードバックのお願いを補足する目的で用意しています。

正確な手順、対象環境、ライセンス、謝辞、既知の制限については、英語版 `README.md` を優先してください。

## 現在の到達点

現時点では、Fedora Linux 6.19.12 環境において、iMac18,3 の内蔵スピーカー再生を確認できています。

確認済みの内容は以下です。

* 内蔵スピーカーから音が出る
* YouTube など通常のデスクトップ再生ができる
* ALSA / PipeWire の analog-stereo 出力で再生できる
* 未改造の Linux 6.19.12 ソースツリーにパッチを適用できる
* CS8409 関連の対象オブジェクトがビルドできる

## このパッチの位置づけ

このパッチは、完成品や upstream-ready な解決策ではありません。

1台の iMac18,3 実機で確認した、実験的な動作結果と調査記録です。
そのため、他の環境、他のカーネルバージョン、他の Mac で同じように動くことは保証していません。

ただし、Fedora 環境で iMac18,3 の内蔵スピーカーを鳴らすために、どのような初期化処理が必要だったかを共有する目的では、有用な記録になると考えています。

## 未対応・未確認の内容

このパッチは、現時点では内蔵スピーカー再生を主な対象にしています。

未対応または未確認の内容は以下です。

* ヘッドフォン切替
* 内蔵マイク入力
* 外部マイク入力
* Apple 純正と同等のスピーカーチューニング
* 他の iMac / MacBook モデル
* 他のカーネルバージョン
* Ubuntu 用パッチの置き換え

## 注意点

デスクトップのサウンド設定で Configuration / Profile を切り替えると、再生状態が一時的に崩れることがあります。

確認した環境では、再度 `Analog Stereo Output` に戻すことで復帰できました。
コマンドによるドライバリセットは不要でした。

ただし、Profile を切り替えた際に音量状態が引き継がれない可能性があります。
その状態で再生すると、想定よりかなり大きな音でノイズが鳴ることがあります。

Configuration / Profile を切り替えて検証する場合は、事前に音量を下げてから試してください。

また、このパッチが対象としているのは analog-stereo の内蔵スピーカー出力経路です。
PipeWire やデスクトップのサウンド設定上で 2.1ch や 4.0ch などの profile が表示される場合がありますが、それらは現時点ではこのパッチで検証済み・対応済みの iMac18,3 内部スピーカーマッピングではありません。

同様の profile 表示は、動作確認済みの Ubuntu 22.04 環境でも観測しているため、このパッチ固有の挙動とは限りません。

## フィードバックのお願い

同じ iMac18,3、または近い構成の Mac でこのパッチを試した方がいれば、検証結果を共有してもらえると助かります。

特に知りたい内容は以下です。

* 機種名
* ディストリビューション
* カーネルバージョン
* パッチ適用の成否
* ビルドの成否
* 内蔵スピーカーが鳴るかどうか
* 音質や左右バランスの印象
* Configuration / Profile 切替時の挙動
* `Analog Stereo Output` に戻したときに復帰するか
* Profile 切替後に大音量ノイズが出るか
* シャットダウン時のポップ音の有無
* ヘッドフォン切替を試した場合の結果
* マイク入力を試した場合の結果

成功報告だけでなく、失敗報告も重要です。
特に、機種、カーネルバージョン、`dmesg` の関連ログがあると、今後の改善に役立ちます。

## この公開について

このリポジトリは、既存の Linux kernel、公開されている先行調査、コミュニティ情報、そして iMac18,3 実機での観測と検証をもとに整理したものです。

単にコードを公開することだけが目的ではなく、Fedora 環境で iMac18,3 の内蔵スピーカーを鳴らすために、どのような観測と修正が必要だったかを共有することを目的としています。

ChatGPT は、ログ整理、仮説整理、コード確認、README 作成補助として使用しました。
実際のコード適用、ビルド、再起動、音声確認は、すべて実機上で手動で行っています。
